# 📚 Data Structure Lab Experiments

A collection of **Data Structures and Algorithms (DSA) lab programs written in C**. This repository contains implementations of fundamental data structures, including trees, hash tables, tries, and disjoint sets.

The goal of this repository is to practice data structure concepts, understand their implementation in C, and maintain a collection of lab experiments for learning and revision.

## 📂 Programs Included

| No. | Program | Description |
|---:|---|---|
| 1 | **AVL Tree** (`AVLtree.c`) | Implementation of a self-balancing binary search tree. |
| 2 | **B-Tree** (`Btree.c`) | Implementation of a tree structure designed for efficient searching and insertion. |
| 3 | **Disjoint Set** (`disjointset.c`) | Implementation of disjoint-set operations for managing groups of elements. |
| 4 | **Hash Table** (`hashtable.c`) | Demonstrates hashing, separate chaining, linear probing, searching, and deletion. |
| 5 | **Trie** (`trie.c`) | Implements a prefix tree for inserting and searching words. |

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the programs:

- A C compiler such as GCC
- Visual Studio Code or another code editor
- Git (optional, for cloning the repository)

### Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/ashthaf/data-structure-lab-experiments.git
```

Navigate to the project folder:

```bash
cd data-structure-lab-experiments
```

### Compile and Run a Program

For example, to run the hash table program:

**1. Compile the source file**

```bash
gcc hashtable.c -o hashtable.exe
```

**2. Execute the program on Windows PowerShell**

```powershell
.\hashtable.exe
```

For other programs, replace `hashtable.c` and `hashtable.exe` with the corresponding source and executable names.

Example for the Trie program:

```bash
gcc trie.c -o trie.exe
```

```powershell
.\trie.exe
```
